# 範本：HTML5 機轉互動頁（05_機轉互動頁.html）

直接產出可在瀏覽器開啟的單一 HTML 檔，不是產生 prompt。

## 規格

1. **單一檔案**：CSS 與 JavaScript 寫在同一檔。外部函式庫只用 cdnjs.cloudflare.com 上指定版本的 Chart.js（例：`https://cdnjs.cloudflare.com/ajax/libs/Chart.js/4.4.1/chart.umd.min.js`），沒有圖表需求就不要載入。
2. **內容**：
   - 頁首：產品名、一句話定位（使用 approved_wording）
   - 機制導覽器：tabs 或分步驟點選，每一步顯示對應成分的角色與說明，搭配簡單的 CSS 動畫
   - 研究背景區：列出研究等級標籤（成分研究／基礎機轉研究等對外用語）與來源連結
   - 頁尾：資料來源列表、「本頁為機轉示意，非成品功效說明」的標註
3. **圖表**：沒有真實人體數據時，圖表必須標示「機轉示意」或「概念模型」，不得畫成療效曲線或前後對比圖。有已查證數據時，標明單位、期間、對照組與來源。
4. **版面**：手機與桌機都能閱讀；文字使用台灣繁體中文；配色清爽專業，避免醫療診斷的視覺暗示。
5. **合規**：頁面所有功效文字只能逐字使用 approved_wording，不得放入內部註記。
6. **完成後**：確認 HTML 標籤完整閉合。若環境有瀏覽器預覽工具，打開檢查互動是否正常；沒有就在交付摘要中說明「未經瀏覽器驗證」。
