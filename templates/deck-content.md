# 範本：提案簡報逐頁稿

寫之前必須先讀 `references/deck-architecture.md` 與 `references/audience-and-delivery.md`。

- 頁數 N 由 Gate 3 決定，不得自行增減。
- 觀看方式為「現場講述」→ 只產出講述版；「會後寄送閱讀」→ 只產出閱讀版；「兩者都要」→ 兩份都產出，頁序與標題完全一致。
- 所有功效宣稱只能逐字使用 approved_wording，並在每頁標註 claim id。

## 共用開頭（兩版都要）

```markdown
# {產品名}｜{簡報目的} 提案簡報（{講述版／閱讀版}）

- 聽眾：{Gate 3 聽眾}
- 會議長度：{分鐘}｜主幹頁數：{N}｜附錄：{有／無，幾頁}
- 本場要對方做的決定：{依簡報目的}

## 頁數分配表
| 幕 | 頁碼 | 頁數 | 本幕重點 |
| --- | --- | --- | --- |
| 封面 | 0 | 1 | |
| 一 現狀與隱形危機 | | | |
| 二 認知破局 | | | |
| 三 關鍵技術與機轉 | | | |
| 四 實證與低阻力體驗 | | | |
| 五 商業落地與行動 | | | |
| 附錄抽屜 | A1– | | |
| 主幹合計 | | {N} | |

## 標題大綱（只看標題就能讀懂整場）
1. …
```

## 講述版：每頁格式（03_簡報_講述版.md）

```markdown
## 第 {n} 頁｜第{幕}幕｜{結論式標題，15 字內}
- 頁面文字：
  - （2–3 點，精簡）
- 建議視覺：
- 講者備註：（50–120 字，口述補充、關鍵數值與出處）
- 銜接句：（帶到下一頁的一句話；最後一頁省略）
- 宣稱來源：cl-○
```

講述版最後附上：

```markdown
## 行前準備清單
（照 deck-architecture.md 第 6 節，PM 自行勾選）
```

## 閱讀版：每頁格式（04_簡報_閱讀版.md）

```markdown
## 第 {n} 頁｜第{幕}幕｜{與講述版相同的標題}
- 內容：（完整論述，含數值、單位、期間、比較基準、條件；講述版放在講者備註的內容寫進這裡）
- 建議視覺：
- 來源：（PMID／DOI／URL，查核日期）
- 宣稱來源：cl-○
```

## 附錄抽屜（兩版相同）

```markdown
## 附錄 A{n}｜{研發／法規／供應／商業}抽屜｜{結論式標題}
- 內容：
- 來源：
```

附錄只放 PM 有提供或已查證的資料。缺的資料寫「［待補：○○］」，不要整頁憑空生成。
