# 範本：NotebookLM 提示詞（07_NotebookLM提示詞.md）

給 PM 手動貼進 NotebookLM 使用。檔案開頭先寫操作步驟，再寫提示詞。變數全部填入實際值。

操作步驟與禁止清單包在 `check:ignore` 標記中，`check_claims.py` 掃描違規詞時會略過；標記要原樣保留。

「被否決原句外流」檢查仍掃全文，包括標記內。禁止清單不得逐字寫出 Gate 4 被否決的原句，要改寫成類別描述，例如「疾病相關功效說法」。

```markdown
<!-- check:ignore-start -->
# NotebookLM 使用步驟
1. 建立新的 notebook。
2. 上傳來源：{列出建議上傳的文獻 PDF／網址，只列已查證的 evidence 來源}，以及「02_對外企劃稿.md」。
   不要上傳 01_內部工作稿.md。
3. 在 Studio 選擇要產出的格式（簡報、報告、語音摘要、影片、心智圖等），把下方提示詞貼進自訂指示。
4. 產出後，用 $bio-marketing 的宣稱規則人工檢查一次：功效說法是否都在核准清單內。
<!-- check:ignore-end -->

# 提示詞
請以上傳的來源為依據，為「{聽眾}」製作關於「{產品名}」的{格式}。
- 情境：{觀看方式}，{會議長度}；若為簡報，主幹 {N} 頁。
- 主軸：{主打協同}，對應客群：{產品目標客群}。
- 結構：現狀與痛點 → 過去做法的盲點 → 機轉與技術 → 研究證據 → 商業價值與下一步（{CTA}）。
- 功效說法只能使用以下用字：{approved_wording 列表}。
- 區分「成品研究」「成分研究」「基礎機轉研究」，不得把細胞或動物研究說成人體效果。
<!-- check:ignore-start -->
- 不使用治療、治癒、預防疾病、保證效果等說法。
<!-- check:ignore-end -->
- 引用時標明來源。
- 使用台灣繁體中文。
```
