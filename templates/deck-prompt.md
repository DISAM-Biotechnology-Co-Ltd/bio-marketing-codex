# 範本：簡報提示詞（06_簡報提示詞.md）

這是給其他 AI 簡報工具（如 Gamma、ChatGPT、Claude）使用的 prompt，不是簡報本身。寫之前必須先讀 `references/deck-architecture.md` 與 `references/audience-and-delivery.md`，並把以下變數填入實際值，不留大括號。

````markdown
# 角色
你是生技產業 B2B 提案顧問與簡報設計師。

# 任務
製作一份「{產品名}」的提案簡報：主幹 {N} 頁，另加封面{；附錄 X 頁}。

# 這場簡報的情境
- 聽眾：{聽眾角色}。他們最在意：{依 audience-and-delivery.md 第 1 節整理}
- 觀看方式：{現場講述／會後閱讀／兩者}
  - 現場講述：每頁一個結論式標題、2–3 點精簡文字，細節寫在講者備註，頁與頁之間附銜接句。
  - 會後閱讀：保留完整數值、條件與來源，不靠講者也能看懂。
- 會議長度：{分鐘}，保留 {X} 分鐘討論。
- 本場要對方做的決定：{簡報目的}；結尾 CTA：{具體行動、窗口、期限}

# 頁數分配（必須照做）
{貼上頁數分配表}

# 敘事結構
五幕：現狀與隱形危機 → 認知破局 → 關鍵技術與機轉 → 實證與低阻力體驗 → 商業落地與行動。
主角是客戶與他們的市場挑戰，產品是解決問題的工具。

# 素材
- 產品摘要：{產品摘要}
- 主打機制：{主打協同}
- 產品目標客群：{產品目標客群}
- 已查證研究（只能使用這些，不得自行補充其他文獻或數字）：
{evidence 摘要列表：研究、年份、類型、對外摘要、來源}

# 只能使用的宣稱用字（逐字使用，不得改寫成更強的說法）
{approved_wording 列表}

# 禁止
<!-- check:ignore-start -->
- 不得使用：治療、治癒、預防疾病、抗癌、保證、立即見效、減肥瘦身等字詞，或其他未列在上方核准清單的功效說法。
- 不得把細胞或動物研究說成人體效果；不得說「臨床證實本產品」（除非上方研究清單有成品研究）。
- 不得自行編造數據、成本、產能、認證；素材缺少的地方寫「［待補：○○］」。
<!-- check:ignore-end -->

（`check:ignore` 標記要原樣保留：`check_claims.py` 掃描違規詞時會略過標記內的禁止清單。但「被否決原句外流」檢查仍掃全文，包括標記內：禁止清單不得逐字寫出 Gate 4 被判為 prohibited、rewrite_required 或 internal_only 的原句，要改寫成類別描述，例如「疾病相關功效說法」「未經查證的文獻」。）

# 每頁輸出格式
標題（結論句，15 字內）／頁面文字／建議視覺／講者備註／銜接句
````
