# DISAM Brand Language

Use only when DISAM context is active.

Preferred communication characteristics:
- technically grounded rather than hype-driven
- B2B ingredient and platform language before consumer-style slogans
- clearly separate verified fact, scientific rationale, and commercial positioning
- emphasize reproducibility, application fit, traceable evidence, and collaboration value

Do not imply that DISAM branding itself is evidence. Product claims still pass the Evidence and Regulatory Gates.
