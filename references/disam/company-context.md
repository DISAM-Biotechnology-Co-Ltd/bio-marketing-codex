# DISAM Company Context

Load this file **only when DISAM context is active**. It must not alter generic bio-marketing behavior for unrelated companies.

DISAM is treated here as a B2B biotechnology and ingredient-platform company. Reusable context includes fungal biotechnology, strain/process development, ingredient commercialization, application development, OEM/formulation collaboration, and science-to-market support.

Distinguish three kinds of statements:
- **company fact** — supported by current approved company materials.
- **platform positioning** — strategic language used to explain the business model.
- **scientific claim** — requires evidence and must pass the normal evidence/regulatory workflow.

Never convert a platform-positioning phrase into scientific proof.
