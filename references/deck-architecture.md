# 簡報架構與頁數分配

寫 `templates/deck-content.md` 或 `templates/deck-prompt.md` 前必讀，並搭配 `audience-and-delivery.md`。

## 1. 骨架：五幕敘事

簡報的主角是「客戶與他們的市場挑戰」，原料是幫客戶解決問題的工具。不要寫成規格陳列。

| 幕 | 名稱 | 要讓聽眾產生的感受 | 內容 |
|---|---|---|---|
| 一 | 現狀與隱形危機 | 共鳴、焦慮 | 品類需求大，但現有方案充滿妥協（例：保健品腥苦、吸收差、吃三天就放棄；保養品刺激、易氧化、黏膩）；研發卡在行銷宣稱需求與製程穩定性之間 |
| 二 | 認知破局 | 好奇 | 指出業界過去的盲點（例：只靠堆疊濃度），提出新的思考角度 |
| 三 | 關鍵技術與機轉 | 理解 | 原料來源與製程門檻、作用機轉、技術如何解決穩定性問題 |
| 四 | 實證與低阻力體驗 | 認同、驚喜 | 已查證的人體研究數據、感官體驗、安定性與起始配方 |
| 五 | 商業落地與行動 | 安心、採取行動 | 單劑成本、供貨與認證、合規宣稱詞庫、具體 CTA |

當產品目標客群是終端消費者或通路、而不是 B2B 原料客戶時，五幕改用 SCQA 對應：情境（第一幕）→ 衝突（第二幕）→ 問題（第三幕）→ 解答（第四、五幕），頁數分配規則不變。

## 2. 頁數分配規則

輸入：PM 在 Gate 3 選定的頁數 N（主幹頁數，不含封面與附錄）。

1. **固定頁**：封面 1 頁，不計入 N。附錄抽屜另計，不計入 N。
2. **N ≤ 4**：第一＋二幕合併 1 頁、第三＋四幕合併 1–2 頁、第五幕 1 頁。合併的頁面標題仍要寫結論。
3. **N ≥ 5**：先給每幕 1 頁（共 5 頁），剩下的 N−5 頁依聽眾加權分配：

| 聽眾 | 優先加頁的幕 |
|---|---|
| 研發／配方 | 第三幕（機轉）、第四幕（實證、安定性、起始配方） |
| 品牌 PM／行銷 | 第一幕（趨勢）、第四幕（感官）、第五幕（宣稱詞庫） |
| 採購／供應鏈 | 第五幕（成本、供貨、認證、條款） |
| 高層／創辦人 | 第一幕（市場規模）、第五幕（護城河、排他合作） |
| 跨部門會審 | 平均分配，第三、四幕各多 1 頁 |
| 通路／經銷 | 第一幕（消費者痛點）、第五幕（話術、素材） |

多選聽眾時，加權取聯集，並在共同關切優先的原則下平均分配。

4. **附錄抽屜**：分兩層，兩者都不計入 N，都要寫進頁數分配表。
   - **必備抽屜**：檔位為「完整」，或 N ≥ 12 且聽眾為多角色時，附加以下抽屜，每個抽屜 1–3 頁。
   - **精簡抽屜**：聽眾為多角色、但不符合必備抽屜條件時（例如標準 10 頁＋研發與品牌 PM），只替主幹放不下的角色細節各加 1 頁，附錄合計最多 2 頁。主幹放得下就不加。
   - 單一聽眾且不符合必備抽屜條件時，不加附錄。
   - 不論哪一層，都只放 PM 有提供或已查證的資料。各抽屜內容如下：
   - 研發抽屜：HPLC 圖譜、加速安定性、配伍禁忌、起始配方細節
   - 法規抽屜：INCI 名稱、原料公告或批號、毒理資料、各市場法規狀態
   - 供應抽屜：產能、認證證書、交貨條款
   - 商業抽屜：階梯報價、排他與授權條件
5. **不設上下限**：自訂頁數照上面規則縮放。只有在 N 少到無法容納 PM 指定的必備內容時，才在大綱前提醒 PM 有哪些內容被合併或移到附錄。
6. 產出前在大綱開頭列出「頁數分配表」（每幕幾頁、附錄幾頁），讓 PM 一眼核對。

## 3. 每頁欄位

講述版（每頁）：

- 標題：一句結論，15 字以內
- 頁面文字：2–3 點，精簡
- 建議視覺：具體描述圖表或圖解
- 講者備註：50–120 字，補充口述內容、數值與來源
- 銜接句：如何帶到下一頁（最後一頁省略）
- 宣稱來源：本頁用到的 claim id，例如 cl-1、cl-3

閱讀版（每頁）：

- 標題：同講述版
- 內容：完整論述，含數值、單位、期間、比較基準、條件
- 建議視覺
- 來源：PMID／DOI／URL 與查核日期
- 宣稱來源：claim id

## 4. 銜接句範例

避免「請看下一頁」這類機械式過場。

| 轉換 | 生硬說法 | 建議寫法 |
|---|---|---|
| 市場 → 機轉 | 接下來看作用原理 | 既然需求這麼迫切，為什麼市面上還沒有讓人有感的產品？問題出在… |
| 機轉 → 人體證據 | 這頁是實驗數據 | 機轉在實驗室成立，放進人體是否依然成立？研發最在意的人體研究結果是… |
| 證據 → 樣品 | 我們也有做樣品 | 數據再漂亮，口感或膚感不好就沒有回購。請各位親自體驗… |
| 樣品 → 配方 | 研發要的加工溫度在這頁 | 大家可能擔心進到現有產線會不會出問題，我們已經把試錯路徑走完… |
| 技術 → 商業 | 最後看報價 | 好的效果如果換來過高成本，就很難普及。我們用每份產品的實際添加成本來看… |

銜接句也是對外內容，同樣受宣稱規則約束。

## 5. 產出前檢核

- [ ] 頁數分配表與 PM 選的頁數一致
- [ ] 只看標題就能讀成完整大綱，且順序對應本次要對方做的決定
- [ ] 每個數據都有 evidence id 或 PM 提供的來源；圖表有單位、期間、比較基準
- [ ] 公司事實缺漏都已標「［待補：○○］」，並列入內部稿補資料清單
- [ ] 選了「高層」聽眾時，結論在前 3 頁出現
- [ ] 講述版與閱讀版的頁序、標題一致
- [ ] 結尾 CTA 有具體動作、窗口、期限

## 6. 行前準備清單（附在講述版最後，供 PM 自行勾選）

- 對方目前主力產品的成分表
- 單劑使用成本換算表（本原料 vs 競品）
- 最新 COA、SDS 與認證證書影本
- 1–2 組起始配方指南
- 感官體驗樣品：標籤清楚、批號與效期確認
- 樣品申請單
- 簡報超連結附錄、內嵌影片已在現場設備測試
- PDF 備份與一頁式摘要
